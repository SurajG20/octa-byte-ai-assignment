# Portfolio Dashboard

## Stack

Next.js
TypeScript
TailwindCSS
Node.js

## APIs

Yahoo Finance
Google Finance

## Features

✓ Live CMP
✓ Live PE Ratio
✓ Latest Earnings
✓ Portfolio Summary
✓ Sector Summary
✓ Automatic Refresh (15 sec)
✓ Caching (5 min)
✓ TanStack Table
✓ Responsive UI

## Run

npm install

npm run dev
